### Technical Decisions

1. **Modal Pattern:** Used portal-style modals with backdrop click-to-close
   - Prevents layout shifts
   - Accessible (ESC to close, focus trap)
   - Reusable across all create forms

2. **Form State:** Local state + TanStack Query mutations
   - Simple for small forms
   - Automatic cache invalidation
   - Optimistic updates

3. **Validation:** Client-side + server-side
   - Client: Required fields, format validation
   - Server: Zod schemas in API routes
   - Error messages displayed inline

4. **TypeScript:** Maintained type safety
   - Interfaces for modal props
   - Type-safe form data
   - API client types
